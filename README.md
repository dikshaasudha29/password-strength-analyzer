
# Password Strength Checker 

A Python-based Password Strength Checker developed as part of the DecodeLabs Cybersecurity Project.

## Features
- Checks password length.
- Detects uppercase letters.
- Detects numeric digits.
- Detects special symbols.
- Classifies password strength as Weak, Medium, or Strong.

## Technologies Used
- Python 3
- VS Code

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python src/password_checker.py
```

4. Enter a password to check its strength.

## Project Objective

To understand Python string handling, conditional statements, password validation, and basic cybersecurity concepts.
